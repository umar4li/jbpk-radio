# 📻 JB KNOWLEDGE PARK — Campus Radio

A luxury retro web radio inspired by **[saloon.wtf](https://saloon.wtf)** featuring the **JB Knowledge Park** campus illustrated background, frosted glass vinyl player, and an extensive collection of full-length Bollywood hits, Slowed & Lofi, Romantic hits, and Evergreen Classics.

---

## 🌟 Key Highlights

1. **Branding: JB KNOWLEDGE PARK**:
   - Official collegiate typography vector logo for **JB KNOWLEDGE PARK**.
   - Subtitle: `JB KNOWLEDGE PARK • 24/7 CAMPUS RADIO`.
   - Clickable logo switcher for customized titles.

2. **Track #1: Aye Meri Natkhati College Ki Ladkiyon**:
   - The opening song is strictly set to **"Aye Meri Natkhati College Ki Ladkiyon"** (*Yeh Dil Aashiqana* — Udit Narayan).

3. **Curated Collections & Mixes**:
   - ✨ **JB Special Mix**: Direct integration of user-curated playlists (*Tera Naam Doon Slowed, Nazar Lagi, Kisi Se Tum Pyar Karo Lofi, Dil Leke Darde Dil, Hun Ishq Main, Vaaroon Forever, Veer-Zaara & YRF Classics*).
   - 🎧 **Slowed & Lofi**: Ambient, chill Bollywood beats.
   - ❤️ **Romantic Melodies**: Soul-stirring love anthems.
   - 📻 **Veer-Zaara & 90s Classics**: Golden era cinematic music.
   - 🎒 **College Nostalgia**: Campus life and friendship tracks.
   - 🎉 **Masti & Party**: High-energy dance bangers.

4. **Continuous Radio Experience (No Numbers / Count System)**:
   - All song numbering and count systems removed for an uninterrupted, elegant radio broadcast vibe.
   - Sleek **`● LIVE`** indicator in the player and smooth audio wave animations.

5. **Saloon.wtf Exact Structure**:
   - **Top-Left**: Real-time Indian Standard Time (IST) clock with blinking colon.
   - **Top-Center**: Dynamic live online badge with pulsing green light (`● 38 online`).
   - **Top-Right**: Wallpaper switcher, Panorama pan toggle, and Playlist drawer.
   - **Bottom Player**: Frosted glass pill (`backdrop-blur-2xl`), rotating vinyl disc (8s spin), interactive seekbar, play/prev/next controls, and volume mute.
   - **Keyboard Shortcuts**: `Space` (Play/Pause), `←` / `→` (Change Track), `M` (Mute), `P` (Playlist), `S` (Shuffle).

## 🚀 How to Host it LIVE (100% Free in 1 Minute)

The project is built with pure HTML5, CSS3, and JavaScript — no database, Node server, or backend setup needed!

### Option 1: Netlify Drop (Easiest — Drag & Drop)
1. Open **[app.netlify.com/drop](https://app.netlify.com/drop)** in your browser.
2. Drag and drop the folder:
   `C:\Users\razau\.gemini\antigravity\scratch\college-nostalgia`
3. Done! Your site will be instantly live with a free HTTPS URL (e.g. `https://jb-radio.netlify.app`).

### Option 2: Vercel CLI (30 Seconds)
1. Open PowerShell and run:
   ```bash
   cd C:\Users\razau\.gemini\antigravity\scratch\college-nostalgia
   npx vercel
   ```
2. Follow the 2 prompts (`Enter` to confirm defaults). You'll receive a live link instantly.

### Option 3: GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings > Pages** and select `main` branch.
3. Your site is live worldwide for free!
